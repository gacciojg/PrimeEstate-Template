## ABOUT THE PROJECT

PrimeEstate is a real estate website template created to showcase properties through a modern, clean and intuitive interface.

The project focuses on responsive design, visual presentation and user experience.

## FEATURES

- Modern and elegant user interface.
- Responsive navigation menu.
- Property listings section.
- About section.
- Contact section.
- Responsive layout for desktop, tablet and mobile devices.

## TECHNOLOGIES

| Technology | Purpose |
|:---:|:---|
| HTML5 | Website structure |
| CSS3 | Styling and layouts |
| Google Fonts | Typography |

## RESPONSIVE DESIGN

The website is optimized for different screen sizes, providing a consistent browsing experience across desktop, tablet and mobile devices.
